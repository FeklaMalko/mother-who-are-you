# МАТЬ, ТЫ КТО ВООБЩЕ?

Самостоятельный сатирический тест о материнских привычках и семейном быте — от ночных кормлений до подросткового «не начинай». Перед тестом указывают количество детей и возраст каждого, включая месяцы для маленьких; это помогает учесть погодков и разницу между детьми в вопросах и контексте результата. Дата рождения мамы по желанию добавляет солнечный знак к шуточному гороскопу. Всего 16 вопросов, восемь архетипов, восемь оригинальных SVG-иллюстраций и 96 шуточных сочетаний «знак × архетип».

**Сайт:** [feklamalko.github.io/mother-who-are-you](https://feklamalko.github.io/mother-who-are-you/)

## Локальный запуск

Откройте `index.html` в современном браузере либо запустите статический сервер из корня проекта, например `python3 -m http.server 8000`, и перейдите на `http://localhost:8000`.

Тесты движка запускаются командой `npm test` (Node.js 20+; сторонние зависимости не нужны).

## Публикация

Сайт публикуется из корня репозитория через GitHub Pages и GitHub Actions. Workflow в `.github/workflows/pages.yml` запускает тесты перед каждым развёртыванием при push в `main`.

## Состав

- `index.html`, `styles.css`, `app.js` — доступный адаптивный интерфейс и локальное прохождение.
- `engine.js` — результаты, общие и возрастные пулы вопросов, детерминированный подсчёт, даты знаков и библиотека из 96 сочетаний.
- `assets/*.svg` — восемь оригинальных сюжетных иллюстраций и фавикон.
- `tests/engine.test.mjs` — проверки баланса, содержания результатов, достижимости архетипов и астрологических границ.

## Критерии приёмки

- [x] Стартовый экран, количество детей, индивидуальный возраст каждого и дата рождения мамы по желанию; всего 16 одноэкранных вопросов и полный экран результата.
- [x] Возрастные пулы вопросов и примеры результата учитывают возраст каждого ребёнка; разница между детьми и количество детей добавляют семейный контекст, не меняя баллы архетипов.
- [x] Ровно восемь достижимых архетипов; у каждого разбор на 150–250 слов, пять ситуаций, три сильные стороны, три привычки, три совета, цитата и SVG.
- [x] 12 солнечных знаков с отдельным разбором в связке с каждым из 8 архетипов и выбранными возрастами детей; астрология не влияет на баллы.
- [x] Локальное прохождение без регистрации и внешних API; возрастные ответы не сохраняются, а дата и возраст не попадают на карточку результата.
- [x] Распространение: системное меню Web Share, копирование текста/ссылки и скачивание PNG; есть повторное прохождение.
- [x] Адаптивная верстка от 320 px, клавиатурный фокус, понятные подписи и режим reduced motion. Примеры не требуют конкретного числа детей.
- [x] GitHub Actions проверяет движок перед публикацией сайта через GitHub Pages.

Тест развлекательный, не оценивает качество материнства и не является психологической диагностикой. Астрологический блок — художественная интерпретация солнечного знака, архетипа и выбранных возрастов детей. Для натальной карты понадобились бы время и место рождения.
