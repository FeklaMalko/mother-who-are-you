# МАТЬ, ТЫ КТО ВООБЩЕ?

Самостоятельный сатирический тест о материнских привычках и семейном быте. 16 вопросов, восемь архетипов, восемь оригинальных SVG-иллюстраций и 96 шуточных сочетаний «знак × архетип». Знак не влияет на результат теста.

**Сайт:** [feklamalko.github.io/mother-who-are-you](https://feklamalko.github.io/mother-who-are-you/)

## Локальный запуск

Откройте `index.html` в современном браузере либо запустите статический сервер из корня проекта, например `python3 -m http.server 8000`, и перейдите на `http://localhost:8000`.

Тесты движка запускаются командой `npm test` (Node.js 20+; сторонние зависимости не нужны).

## Публикация

Сайт публикуется из корня репозитория через GitHub Pages и GitHub Actions. Workflow в `.github/workflows/pages.yml` запускает тесты перед каждым развёртыванием при push в `main`.

## Состав

- `index.html`, `styles.css`, `app.js` — доступный адаптивный интерфейс и локальное прохождение.
- `engine.js` — результаты, вопросы, детерминированный подсчёт, даты знаков и библиотека из 96 сочетаний.
- `assets/*.svg` — восемь оригинальных сюжетных иллюстраций и фавикон.
- `tests/engine.test.mjs` — проверки баланса, содержания результатов, достижимости архетипов и астрологических границ.

## Критерии приёмки

- [x] Стартовый экран, дата по желанию, 16 одноэкранных вопросов и полный экран результата.
- [x] Ровно восемь достижимых архетипов; у каждого разбор на 150–250 слов, пять ситуаций, три сильные стороны, три привычки, три совета, цитата и SVG.
- [x] 12 знаков с отдельными текстами и 96 уникальных комментариев для сочетаний знака и архетипа; астрология не влияет на баллы.
- [x] Локальное прохождение без регистрации, персональных данных и внешних API; дату нельзя увидеть на карточке результата.
- [x] Распространение: системное меню Web Share, копирование текста/ссылки и скачивание PNG; есть повторное прохождение.
- [x] Адаптивная верстка от 320 px, клавиатурный фокус, понятные подписи и режим reduced motion.
- [x] GitHub Actions проверяет движок перед публикацией сайта через GitHub Pages.

Тест развлекательный, не оценивает качество материнства и не является психологической диагностикой. Тексты астрологии — художественная шутка.
